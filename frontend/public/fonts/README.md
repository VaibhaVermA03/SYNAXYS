# Fonts

`geist-pixel-circle.woff2` is **Geist Pixel (Circle variant)** by Vercel, licensed under the SIL Open Font License 1.1
(<https://github.com/vercel/geist-font>). It is downloaded from the official repository by `npm run fonts:install`
(runs automatically before `npm run dev` / `npm run build`). After the first successful download, **commit the file**
(and `GEIST-LICENSE.txt`) so builds do not need network access. Keep the licence file next to the font when you redistribute it.

If the file is absent the app still works: headings fall back to a monospace font.
